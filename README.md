# Clover Green Power

Premium multi-page website for Clover Green Power — a renewable energy company focused on Nigeria.

Built with **HTML**, **CSS**, and **JavaScript** only. No build step required.

## Pages

| File | Description |
|------|-------------|
| `index.html` | Home — hero, stats, technologies, testimonials |
| `about.html` | Company story, vision, leadership, timeline |
| `investment.html` | Investor pitch, charts, tiers, inquiry form |
| `contact.html` | Contact form, map, FAQ |

## Project Structure

```
├── index.html
├── about.html
├── investment.html
├── contact.html
├── css/
│   └── styles.css
└── js/
    ├── data.js
    └── main.js
```

## Run Locally

```bash
python3 -m http.server 8080
```

Open [http://localhost:8080](http://localhost:8080).

## Deploy

Upload the project folder to any static host: Netlify, GitHub Pages, Cloudflare Pages, S3, etc.
